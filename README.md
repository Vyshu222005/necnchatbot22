# NECN College Companion

Build a complete AI College Enquiry Chatbot named NECN AI Assistant.

Requirements:

Modern responsive UI.

College logo on home page.

ChatGPT-style chat interface.

Student can ask questions naturally.

Support English and Telugu.

Mobile friendly.

Pages:

Home

Chatbot

About College

Contact

Admin Dashboard

Chatbot Features:

Answer questions about admissions, courses, fees, hostel, placements, transport, scholarships, library, laboratories and contact details.

Use AI to understand different ways of asking the same question.

Maintain conversation history.

Show typing animation.

Voice input support.

Voice output support.

Admin Dashboard:

Add/Edit/Delete FAQs.

Upload PDF brochures.

Upload fee structures.

Upload placement reports.

Manage courses and hostel information.

Database:
Create tables for FAQs, Courses, Hostel, Contact Information and Uploaded Documents.

AI Features:

Integrate Gemini API.

Use uploaded documents as knowledge base.

If information is not found, politely inform the user.

Answer only college-related questions.

Deployment Ready:

Generate complete production-ready application.

Include authentication for admin.

Generate database schema and API integration automatically.
